# 🤝 Contributing to SoloLaunch

Thank you for contributing to SoloLaunch! SoloLaunch is a free, open-source tool built to help solo developers discover trending software and find viable project ideas backed by real data.

---

## Code of Conduct

We are committed to providing a welcoming, transparent, and respectful experience for all contributors regardless of background or experience level.

---

## How Can You Contribute?

1. **Add a Data Source**: Check out [docs/data-sources.md](docs/data-sources.md) to add support for a new registry or ecosystem.
2. **Improve Idea Retrieval**: Help refine prompts and gap detection heuristics in `src/ai/`.
3. **Enhance Frontend UX**: Improve sorting, filtering, animations, and accessibility in the UI.
4. **Report Bugs**: Open an issue on GitHub with reproduction steps.

---

## Pull Request Guidelines

1. Fork the repo and create your branch from `main`:
   ```bash
   git checkout -b feature/my-cool-feature
   ```
2. Adhere to TypeScript strict mode and formatting conventions.
3. Keep PRs focused on a single feature or bug fix.
4. Submit PR to `DreamFaang78/sololaunch`!
